# AI 健康助手（AI Health Assistant）

## 变更 ID
`03-ai-health-assistant`

## 状态
**待启动**

---

## 1. 需求概述

为用户提供一个 AI 驱动的健康专家对话界面，用户可以咨询饮食搭配、营养知识、运动建议等问题，AI 基于用户的健康数据（饮食/运动/体重）给出个性化回答。

**目标用户**：所有用户，尤其是需要专业健康指导的用户  
**优先级**：P0（MVP 差异化核心功能）

---

## 2. 功能范围

### 2.1 AI 对话界面

| 功能 | 描述 |
|-----|------|
| 对话列表 | 显示当前会话所有消息（用户消息 + AI 回复） |
| 发送消息 | 输入文本，发送给 AI 服务 |
| 消息气泡 | 用户消息右对齐（蓝色），AI 消息左对齐（绿色） |
| 加载状态 | AI 正在生成回复时显示打字机效果或骨架屏 |
| 清空对话 | 一键清空当前会话 |
| 上下文记忆 | AI 能记住当前对话历史（最近 10 轮） |

### 2.2 健康上下文注入

AI 请求时自动携带以下用户数据作为系统提示词上下文：

- 用户基本信息（年龄、体重、身高、性别）
- 今日饮食记录（已摄入热量/蛋白质/碳水/脂肪）
- 今日运动记录（消耗热量）
- 当前健康目标（减重/增肌/维持）

### 2.3 快捷问题卡片

页面底部显示预设快捷问题按钮，用户一键发送：

- "今天的饮食健康吗？"
- "我今天还能吃什么？"
- "适合上班族的运动有哪些？"
- "如何改善久坐带来的健康问题？"

### 2.4 对话管理

| 功能 | 描述 |
|-----|------|
| 多会话支持 | 保存历史会话列表（最多保留 20 个） |
| 切换会话 | 从侧边栏选择历史会话 |
| 新建会话 | 创建新对话 |
| 删除会话 | 从历史列表中删除某会话 |

## 4. 数据模型

### 4.1 对话消息（ChatMessage）
```typescript
interface ChatMessage {
  id: string;
  session_id: string;
  role: 'user' | 'assistant';
  content: string;
  created_at: string;
}
```

### 4.2 对话会话（ChatSession）
```typescript
interface ChatSession {
  id: string;
  user_id: string;
  title: string;          // 自动生成（取第一条用户消息前20字）
  messages: ChatMessage[];
  created_at: string;
  updated_at: string;
}
```

### 4.3 AI 请求Payload
```typescript
interface AIChatRequest {
  session_id: string;
  user_message: string;
  user_context: {
    age?: number;
    weight?: number;    // kg
    height?: number;    // cm
    gender?: 'male' | 'female';
    goal?: string;
    today_nutrition?: {
      calories: number;
      protein: number;
      carbs: number;
      fat: number;
    };
    today_activity?: {
      calories: number;
      duration: number;
    };
  };
}
```

## 5. API 接口设计

| 方法 | 路径 | 描述 |
|-----|------|------|
| GET | `/api/ai/sessions` | 获取会话列表 |
| POST | `/api/ai/sessions` | 创建新会话 |
| DELETE | `/api/ai/sessions/:id` | 删除会话 |
| GET | `/api/ai/sessions/:id/messages` | 获取某会话消息 |
| POST | `/api/ai/chat` | 发送消息并获取 AI 回复 |
| GET | `/api/ai/user-context` | 获取用户健康上下文（供 AI 使用） |

> AI 对话接入方案：后端转发至 Gemini API / OpenAI API
