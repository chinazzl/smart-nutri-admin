# 运动追踪（Activity Tracker）

## 变更 ID
`02-activity-tracker`

## 状态
**待启动**

---

## 1. 需求概述

用户可以记录每日运动（步行、跑步、骑行、力量训练等）和日常活动（步数、站立时长），系统计算卡路里消耗并与目标对比。

**目标用户**：久坐上班族、健身爱好者  
**优先级**：P0（MVP 核心功能）

---

## 2. 功能范围

### 2.1 运动类型管理

| 运动类型 | 消耗系数 |
|---------|---------|
| 步行 | ~4 kcal/kg/h |
| 慢跑 | ~8 kcal/kg/h |
| 快跑 | ~12 kcal/kg/h |
| 骑行 | ~8 kcal/kg/h |
| 游泳 | ~10 kcal/kg/h |
| 力量训练 | ~6 kcal/kg/h |
| 瑜伽/拉伸 | ~3 kcal/kg/h |
| 办公室微运动 | ~2.5 kcal/kg/h |
| 站立办公 | ~1.5 kcal/kg/h |

### 2.2 运动记录

| 功能 | 描述 |
|-----|------|
| 快速添加运动 | 选择运动类型 + 输入时长（分钟）+ 消耗自动计算 |
| 每日步数记录 | 输入当日步数，自动估算卡路里 |
| 历史记录查看 | 日历视图查看历史运动数据 |
| 删除记录 | 删除单条运动记录 |

### 2.3 运动消耗计算

- **公式**：消耗(kcal) = 运动系数 × 体重(kg) × 时长(h)
- 体重数据从用户 Profile 读取（未设置则使用默认值 60kg）

### 2.4 久坐提醒（可选，后续扩展）

- 设置提醒时间，到点弹出通知
- 记录每日站立/活动时长

## 4. 数据模型

### 4.1 运动记录（ActivityLog）
```typescript
interface ActivityLog {
  id: string;
  user_id: string;
  date: string;           // YYYY-MM-DD
  activity_type: ActivityType;
  duration: number;       // 分钟
  calories: number;        // 计算后消耗 kcal
  steps?: number;          // 步数（仅步数记录时有值）
  created_at: string;
}
```

### 4.2 运动类型枚举
```typescript
type ActivityType =
  | 'walking'      // 步行
  | 'jogging'      // 慢跑
  | 'running'     // 快跑
  | 'cycling'     // 骑行
  | 'swimming'    // 游泳
  | 'strength'    // 力量训练
  | 'yoga'         // 瑜伽/拉伸
  | 'micro_workout' // 办公室微运动
  | 'standing'     // 站立办公
  | 'steps';       // 步数记录
```

### 4.3 运动消耗系数
```typescript
const ACTIVITY_MET: Record<ActivityType, number> = {
  walking: 4,
  jogging: 8,
  running: 12,
  cycling: 8,
  swimming: 10,
  strength: 6,
  yoga: 3,
  micro_workout: 2.5,
  standing: 1.5,
  steps: 0.04, // kcal/步
};
```

## 5. API 接口设计

| 方法 | 路径 | 描述 |
|-----|------|------|
| GET | `/api/activity/logs?date=YYYY-MM-DD` | 获取某日运动记录 |
| POST | `/api/activity/logs` | 新增运动记录 |
| PUT | `/api/activity/logs/:id` | 更新运动记录 |
| DELETE | `/api/activity/logs/:id` | 删除运动记录 |
| GET | `/api/activity/summary?date=YYYY-MM-DD` | 获取当日运动汇总 |
