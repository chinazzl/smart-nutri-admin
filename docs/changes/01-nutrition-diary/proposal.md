# 饮食日记（Nutrition Diary）

## 变更 ID
`01-nutrition-diary`

## 状态
**待启动**

---

## 1. 需求概述

用户可以每日记录三餐及加餐摄入的食物，系统自动计算营养素（热量、蛋白质、碳水、脂肪），并与每日目标对比展示。

**目标用户**：所有用户，尤其是需要控制饮食的用户  
**优先级**：P0（MVP 核心功能）

---

## 2. 功能范围

### 2.1 饮食记录（CRUD）

| 功能 | 描述 |
|-----|------|
| 新增记录 | 添加一餐记录（早餐/午餐/晚餐/加餐），包含食物名称、重量（克）、营养素数据 |
| 编辑记录 | 修改已有食物记录 |
| 删除记录 | 删除单条食物记录 |
| 按日查看 | 日历选择器切换日期，查看当日所有饮食记录 |
| 餐次分类 | 按早/午/晚/加餐分组展示 |

### 2.2 营养素计算

| 营养素 | 说明 |
|-------|------|
| 热量 (kcal) | 每餐及当日汇总 |
| 蛋白质 (g) | 每餐及当日汇总 |
| 碳水化合物 (g) | 每餐及当日汇总 |
| 脂肪 (g) | 每餐及当日汇总 |

> 数据来源：前端内置食物营养库（JSON 文件）或后端 API

### 2.3 目标对比

- 设定每日营养素目标（热量 / 蛋白质 / 碳水 / 脂肪）
- 环形进度图展示当日已摄入 vs 目标
- 超出/未达目标颜色提示（绿色=达标，橙色=接近，红色=超标）

### 2.4 食物搜索

- 输入食物名称，搜索食物库
- 显示常见食物候选列表（支持模糊搜索）
- 支持自定义添加新食物

## 4. 数据模型

### 4.1 食物（Food）
```typescript
interface Food {
  id: string;
  name: string;         // 食物名称
  calories: number;     // kcal/100g
  protein: number;     // g/100g
  carbs: number;       // g/100g
  fat: number;         // g/100g
  serving_unit: string; // 份量单位
}
```

### 4.2 饮食记录（NutritionLog）
```typescript
interface NutritionLog {
  id: string;
  user_id: string;
  date: string;        // YYYY-MM-DD
  meal_type: 'breakfast' | 'lunch' | 'dinner' | 'snack';
  food: Food;
  weight: number;      // 摄入重量（克）
  calories: number;    // 计算后热量
  protein: number;
  carbs: number;
  fat: number;
  created_at: string;
}
```

### 4.3 每日目标（DailyGoal）
```typescript
interface DailyGoal {
  calories: number;  // 默认 2000 kcal
  protein: number;    // 默认 60g
  carbs: number;      // 默认 250g
  fat: number;        // 默认 65g
}
```

## 5. API 接口设计

| 方法 | 路径 | 描述 |
|-----|------|------|
| GET | `/api/nutrition/logs?date=YYYY-MM-DD` | 获取某日饮食记录 |
| POST | `/api/nutrition/logs` | 新增一条饮食记录 |
| PUT | `/api/nutrition/logs/:id` | 更新饮食记录 |
| DELETE | `/api/nutrition/logs/:id` | 删除饮食记录 |
| GET | `/api/nutrition/foods?keyword=xxx` | 搜索食物库 |
| GET | `/api/nutrition/goals` | 获取每日目标 |
| PUT | `/api/nutrition/goals` | 更新每日目标 |
