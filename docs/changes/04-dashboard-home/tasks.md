   - `NutritionSummary` — 营养摄入汇总
   - `DayData` — 单日数据点
2. 创建 `src/stores/dashboard.ts` Pinia store：
   - `summary` — 仪表盘汇总数据
   - `isLoading` — 加载状态
   - `fetchSummary(date)` — 获取汇总数据 action
   - `fetchDailyTip()` — 获取 AI 提示 action

## T4: 核心指标卡片（4列）

**目标**：用 4 个卡片展示当日健康核心数据

### 步骤
1. **整体布局**：使用 `el-row :gutter="16"` + `el-col :xs="24" :sm="12" :md="6"` 实现响应式 4 列
2. **卡片1 — 热量摄入**：
   - 标题："今日热量"
   - ECharts 环形图（已摄入 / 目标）
   - 底部文字：`1200 / 2000 kcal`
   - 颜色逻辑：<80% 绿色，80-100% 橙色，>100% 红色
3. **卡片2 — 营养素分布**：
   - 标题："营养素"
   - 3 个 `el-progress` 进度条：蛋白质 / 碳水 / 脂肪
   - 每条显示：`蛋白质 45/60g 75%`
4. **卡片3 — 运动消耗**：
   - 标题："运动消耗"
   - ECharts 环形图（已消耗 / 目标）
   - 底部文字：`300 / 400 kcal`
5. **卡片4 — 体重记录**：
   - 标题："体重"
   - 大字号显示当前体重：`68.5 kg`
   - 趋势箭头 + 较上周变化：`↓ 0.8kg`
   - 底部文字：`较上周下降`

### 验收
- [ ] 4 个卡片在桌面端并排显示
- [ ] 环形图和进度条正确显示数据
- [ ] 移动端自动切换为 2 列或 1 列布局

## T7: 趋势图表（ECharts）

**目标**：用折线图展示近 7 日数据趋势

### 步骤
1. **热量趋势图**：
   - 标题："近7日热量摄入"
   - X 轴：日期（5/21, 5/22...）
   - Y 轴：热量（kcal）
   - 数据：`weeklyNutrition` 数组
   - 目标线：虚线水平线（2000 kcal）
2. **体重趋势图**：
   - 标题："近7日体重变化"
   - X 轴：日期
   - Y 轴：体重（kg）
   - 数据：`weeklyWeight` 数组
   - 平滑曲线（`smooth: true`）
3. **图表容器**：
   - 使用 `el-row` 上下排列两个图表
   - 图表高度：`300px`
   - 使用 `ResizeObserver` 监听容器宽度变化，实现响应式

### 验收
- [ ] 热量趋势折线图正常显示
- [ ] 体重趋势折线图正常显示
- [ ] 数据为空时图表不报错

## T8: 集成与优化

**目标**：接入真实模块数据，完善体验细节

### 步骤
1. **数据聚合**（各模块完成后）：
   - 热量数据：从 `01-nutrition-diary` store 获取今日饮食汇总
   - 运动数据：从 `02-activity-tracker` store 获取今日运动消耗
   - 打卡状态：综合判断今日是否有记录
2. **骨架屏**：
   - 使用 `el-skeleton` 在数据加载时显示骨架屏
   - 包裹所有数据展示区域
3. **空数据处理**：
   - 无任何记录时，卡片显示 `--` 占位
   - 趋势图为空时显示「暂无数据」提示
4. **移动端适配**：
   - 确保 4 列卡片在手机上变为 1-2 列
   - 趋势图支持横向滚动
   - 快速操作按钮保持可点击大小（至少 44px）

### 验收
- [ ] 数据加载时显示骨架屏
- [ ] 无数据时 UI 不崩溃
- [ ] 真实数据接入后数据正确
- [ ] 手机屏幕完全可用
