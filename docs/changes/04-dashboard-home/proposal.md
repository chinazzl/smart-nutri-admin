## 1. 需求概述

健康仪表盘是用户登录后的首页，汇聚展示用户当日的健康核心数据（饮食/运动/体重/AI建议），让用户一目了然地了解自己当天的健康状态。

**目标用户**：所有用户  
**优先级**：P0（MVP 入口页面）

---

## 2. 功能范围

### 2.1 今日健康总览

| 卡片 | 数据来源 | 展示内容 |
|-----|---------|---------|
| 热量总览 | 饮食日记 | 今日已摄入 / 目标 + 环形图 |
| 营养素分布 | 饮食日记 | 蛋白质/碳水/脂肪 三项进度条 |
| 运动消耗 | 运动追踪 | 今日消耗 / 目标 + 环形图 |
| 体重记录 | 身体数据 | 最新体重 + 趋势箭头（较上周） |

### 2.2 今日打卡状态

| 功能 | 描述 |
|-----|------|
| 饮食打卡 | 今日是否有饮食记录（✅/❌） |
| 运动打卡 | 今日是否有运动记录（✅/❌） |
| 饮水打卡 | 今日饮水量（后续扩展） |

### 2.3 AI 健康提示

- 每次进入仪表盘，从 AI 服务获取一条个性化的每日健康小贴士
- 展示在卡片中，带 💡 图标
- 可一键跳转到 AI 助手提问

### 2.4 快速操作入口

| 入口 | 描述 |
|-----|------|
| + 记录饮食 | 跳转到饮食日记添加页面 |
| + 记录运动 | 跳转到运动追踪添加页面 |
| AI 助手 | 跳转到 AI 健康助手 |

### 2.5 数据趋势图表

使用 ECharts 渲染近 7 日健康数据趋势：

| 图表 | 内容 |
|-----|------|
| 热量趋势图 | 近 7 天每日摄入热量折线图 |
| 体重趋势图 | 近 7 天体重折线图 |

## 4. 数据模型

### 4.1 仪表盘摘要数据
```typescript
interface DashboardSummary {
  date: string;              // 今日日期
  nutrition: {
    consumed: NutritionSummary;
    goal: DailyGoal;
  };
  activity: {
    consumed: number;         // 今日消耗 kcal
    goal: number;             // 运动目标 kcal
  };
  weight: {
    current: number;          // 最新体重 kg
    change: number;           // 较上周变化 kg
  };
  checkin: {
    nutrition: boolean;
    activity: boolean;
    water: boolean;
  };
  aiTip?: string;             // AI 每日提示
  weeklyNutrition: DayData[]; // 近7日饮食数据
  weeklyWeight: DayData[];    // 近7日体重数据
}

interface DayData {
  date: string;
  value: number;
}
```

## 5. API 接口设计

| 方法 | 路径 | 描述 |
|-----|------|------|
| GET | `/api/dashboard/summary?date=YYYY-MM-DD` | 获取当日仪表盘汇总数据 |
| GET | `/api/dashboard/ai-tip` | 获取 AI 每日健康提示 |
| GET | `/api/dashboard/weekly?metric=calories\|weight` | 获取近7日趋势数据 |
