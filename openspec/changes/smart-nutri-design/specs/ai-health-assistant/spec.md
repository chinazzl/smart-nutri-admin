## ADDED Requirements

### Requirement: AI 对话中的个性化健康上下文注入
系统 SHALL 在用户与AI对话时，自动携带用户的最新健康指标数据，以保证AI回复的绝对科学化和个性化。
- 第一步：当用户在输入框发送提问时，系统静默收集用户最新的身体指标数据（身高、体重、BMI、基础代谢率BMR、目标摄入卡路里）。
- 第二步：系统查询用户今日饮食记录（已摄入热量、碳水、蛋白质、脂肪）和今日运动消耗值。
- 第三步：系统将上述数据格式化为上下文 JSON 对象，并拼接入系统提示词（System Prompt）或者 AI 请求 Payload 的 Context 字段中发送给后端接口。
- 第四步：AI 服务结合这些精确数据进行计算，返回包含用户具体数值的科学点评与个性化饮食运动建议。

#### Scenario: AI基于上下文准确回答今日摄入评估
- **WHEN** 用户今日已摄入 1900 kcal（目标 2000 kcal），提问“我今天晚餐还能吃什么？”
- **THEN** 系统发送的请求中必须包含“今日已吃：1900kcal，目标：2000kcal”的上下文，AI必须给出准确的差值建议（例如：“您今天还可以再摄入 100 kcal，建议吃一个中等大小的苹果或一杯脱脂酸奶”）

### Requirement: 交互式多会话对话界面
系统 SHALL 提供流畅的卡片式多会话对话界面，并支持Markdown渲染。
- 第一步：系统在左侧会话侧边栏中渲染当前用户的会话历史列表，并在顶部提供“新建会话”和“清空当前会话”的按钮。
- 第二步：用户在输入框中输入消息并点击发送（或按 Enter 键），消息卡片显示在右侧蓝色背景气泡中，输入框清空。
- 第三步：系统立即显示打字机效果的骨架屏占位卡片，说明 AI 正在思考中，并锁定发送按钮防止重复提交。
- 第四步：AI 响应后，系统采用 Markdown 解析渲染器将 AI 文本输出为漂亮的 HTML（包含加粗、列表、表格和缩进），并在左侧绿色背景气泡中展示。
- 第五步：系统将消息滚动区域（el-scrollbar）平滑滚动到底部，保证最新消息始终可见。

#### Scenario: 发送消息并渲染 Markdown 格式回复
- **WHEN** 用户新建会话，输入“给我写一个减脂一日三餐食谱”并发送，AI 返回包含 Markdown 表格的推荐食谱
- **THEN** 界面必须立即以骨架屏加载，AI回复时将 Markdown 表格正确渲染为 HTML Table 标签样式，且列表滚动高度自动设为最大，保证回复内容完全可见
